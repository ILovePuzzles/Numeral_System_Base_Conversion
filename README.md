# Numeral_System_Base_Conversion
This program allows to convert the representation of a real number from an integer base to another, from base 2 up to base 36. Keep in mind that conversion of fractional values between coprime bases is of limited precision, due to the precision limit inherent to computer's fractional arithmetic.

The newest version of this algorithm allows the user to input periodic values directly. Also, the algorithm now specifies whether or not a periodic value has a period length that exceeds the cutoff limit of the algorithm.

You can compare the results of this algorithm with Wolfram Alpha's base conversion : https://www.wolframalpha.com/examples/mathematics/numbers/base-conversions
